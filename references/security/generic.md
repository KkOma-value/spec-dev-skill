# 通用安全检查

- 只审查需求变更和受影响调用链；基线遗留问题单独标注，不混入新增问题。
- 搜索疑似凭证赋值、私钥头、Bearer Token、云访问密钥；排除测试假值后人工确认。
- 跟踪所有外部输入到数据库、命令、模板、URL、文件路径和反序列化入口。
- 敏感操作确认认证、授权、资源归属、审计日志、速率限制。
- 检查错误响应、日志、序列化对象是否泄露密码、Token、密钥、内部堆栈或个人数据。
- 文件上传校验类型、大小、文件名、存储路径；规范化后确认仍位于允许根目录。
- SSRF 入口使用协议/主机 allowlist，解析 DNS 后阻止内网、环回、链路本地地址，并限制重定向。
- 依赖清单或锁文件变化才运行生态依赖审计；记录命令、退出码、漏洞 ID 与修复版本。
